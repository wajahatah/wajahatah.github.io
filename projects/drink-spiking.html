Drink Spiking Detection

A real-time computer vision system to detect drink spiking behavior from CCTV footage. The pipeline combines YOLO-based glass detection with pose estimation and heuristic reasoning to flag suspicious activity around a detected glass, and is deployed live on public CCTV cameras.

Key Responsibilities

  • Experimented with different heuristic approaches to detect drink spiking
  • Integrated and tested multiple models to get the best detection performance
  • Implemented SAHI (Slicing Aided Hyper Inference) with YOLO to detect glasses reliably
  • For each detection, extracted the tile with padding and ran a MediaPipe pose model on it, then applied a heuristic approach on top of the pose output
  • Improved detection accuracy up to 65%
  • Reduced inference pipeline latency from 100ms to 10ms
  • Deployed the system on public CCTV cameras
