Personal AI Assistant

A progress-aware conversational task assistant for daily task management on Telegram and Discord. Users describe their tasks in natural language, the assistant preprocesses them into structured tasks with a start time and deadline, and then tracks each task's progress, reminding and checking in with the user interactively as the deadline approaches.

Key Responsibilities

  • Parsed tasks from free-form natural language using a pluggable LLM layer (OpenAI, Gemini, Anthropic, Ollama, HuggingFace), validating deadlines and durations before persisting them
  • Designed a deterministic, rule-based state inference engine (no ML) to track each task's progress through NOT_STARTED, ACTIVE, AT_RISK, STALLED, COMPLETED, and DROPPED states
  • Built an intervention engine that decides when to send reminders, status polls, urgent polls, and escalations based on time remaining, with cooldowns to avoid over-notifying the user
  • Implemented a platform-adapter layer so the same core logic runs over both Telegram and Discord through a single normalized message interface
  • Added per-user clock-offset calibration so reminders and the daily summary fire at the user's actual local time regardless of server timezone
  • Built a conversational HELP flow where the assistant interactively chats with the user through an LLM when they're stuck on a task, keeping full conversation history per task
  • Built a daily summary dispatcher that reports completed and stalled tasks along with the day's agenda at the user's configured local time
