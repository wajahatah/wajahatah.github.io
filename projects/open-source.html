Docling Custom OCR Plugin

While integrating a custom OCR service with Docling to process uploaded documents, generate chunks, and create embeddings for downstream AI workflows, we found that Docling officially supports custom OCR integration but has no clear or maintainable way to implement it. The common approach was to modify the library's source code directly, which creates a long-term maintenance problem since those changes can be lost or become incompatible on every library update.

After digging deeper into Docling's architecture, we found a cleaner solution: implementing the integration through a plugin-based approach instead of modifying the library itself. The result is a reusable plugin that lets users connect their own OCR service simply by configuring an OCR endpoint through environment variables. Once installed, it works seamlessly with Docling's existing pipeline — upload a document, let the OCR process the content, and Docling handles the rest.

The project has been open-sourced for the broader community.

Arabic OCR Translator (Chrome Extension)

Built while preparing for an Arabic language exam covering books entirely in Arabic. No Chrome extension fit the need of translating selected Arabic text inline, right where it was being read, without switching tabs or copy-pasting into Google Translate — so I built one.

The extension translates any text selected on any Chrome page and displays the translation in a floating popup right next to the selection. For Quranic text specifically, it also identifies the verse and shows the surah reference alongside the translation.

The more interesting challenge was scanned PDFs — books that are images, not selectable text. For that, OCR support was added with three backends depending on setup: a local Tesseract.js server (Node, fully offline, no API key), a local EasyOCR server (Python, deep learning, higher accuracy), and the OCR.space cloud API (no local setup, free tier). The extension also intercepts PDF navigation and loads files through a built-in viewer so translation works there too.

The whole project is open source.
