ML Algorithm

Machine Learning Projects

A collection of machine learning projects applying classical algorithms and data-balancing techniques to real-world classification problems in healthcare and finance.

Predicting Heart Stroke Risk Using Machine Learning Models and Data Balancing Techniques

Trained and compared three machine learning models — Random Forest, Gradient Boosting, and SVM — using data-balancing techniques (SMOTE, random oversampling, and random undersampling) to predict heart stroke risk on an imbalanced clinical dataset.

Comparative Analysis of Machine Learning Algorithms for Credit Card Detail Classification

Built and compared Random Forest, SVM, and KNN classifiers to detect fraudulent credit card transactions on a Kaggle dataset, evaluating models on accuracy and F1 score.

Comparative Analysis of Machine Learning Algorithms for Heart Attack Prediction through ECG Analysis

Compared Random Forest, SVM, and KNN classifiers on ECG signal data to predict heart attack risk, evaluating models on accuracy, precision, recall, and F1 score.
