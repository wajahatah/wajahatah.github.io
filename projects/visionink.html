VisionInk-AI Air Studio

An experimentation project exploring Vision-Language Models (VLM), diffusion, and CLIP together. The plan is to implement a VLM that properly detects what the user is writing in the air or on a surface, then generate an image based on that text. When the user draws an object instead, the VLM detects it and converts it into proper text or an image, as per the user's need. The VLM will be fine-tuned further and more features will be implemented soon.
